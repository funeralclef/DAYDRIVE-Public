# lucide-animated source notice

DAYDRIVE's native `AnimatedIcon` control ports selected icon shapes and semantic
hover animation behavior from `lucide-animated`:

- Source: https://github.com/pqoqubbw/icons
- Upstream icon shapes: https://github.com/lucide-icons/lucide
- lucide-animated license: MIT
- Lucide icon license: ISC

The application uses native Avalonia drawing and timing rather than the React
and Motion runtime from the upstream web components. Stroke width is adjusted
to 2.25 for legibility in DAYDRIVE's compact interface.
